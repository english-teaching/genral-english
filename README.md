# PDF Library — GitHub Pages Template

## इस्तेमाल
1. `data.js` खोलें।
2. `PDFs` array में अपनी PDF की जानकारी डालें।
3. `url` में public PDF/view link डालें।
4. चाहें तो `downloadUrl` में अलग direct-download link डालें।
5. सभी files GitHub repository में upload करें।
6. GitHub में Settings → Pages → Deploy from branch चुनें और `main` / root चुनें।
7. कुछ समय बाद आपकी public website का URL मिल जाएगा।

## Google Drive
Google Drive में PDF/folder को public viewer access दें और उसका share link `url` में डालें। ध्यान रखें कि Google Drive के share links हमेशा direct-download links नहीं होते; इसलिए "देखें" और "डाउनलोड" व्यवहार link/provider के अनुसार बदल सकता है।
